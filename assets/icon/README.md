# App Icon

The app icon should be placed in this directory with the following specifications:

1. **icon.png** - Main app icon (1024x1024px)
   - Should be the fox character running with checkmark and city background
   - Teal/turquoise background (#1CD8B9)
   - Orange fox character (#FD9B28)
   - UN logo in bottom right corner

2. **adaptive-icon.png** - Android adaptive icon (foreground element)
   - Same as main icon but with transparent background
   - Used for Android adaptive icons

3. **splash-icon.png** - Splash screen icon
   - Centered version of the app icon
   - Used for the loading screen

The icon design should match the image shown in the design mockup with the fox character running, a checklist, buildings in the background, and the UN-Habitat logo in a shield.
